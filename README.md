# The Americas since 1492

An animated map of the Americas from 1492 to today. It shows population by country year by year, along with the ships that crossed the Atlantic, including the transatlantic slave trade, and later migration flows. Data comes from Our World in Data, SlaveVoyages, US DHS, and Statistics Canada.

**Live:** https://micjm.github.io/americas-viz/

```sh
npm install
npm run dev     # local dev server
npm run build   # static build in dist/
npm run data    # rebuild public/data from the raw sources
```

This is a demo project for [Agent Duel](https://github.com/bottomless/agent-duel), blinded battles between coding agents.
